## Missing-lemma registry

### A. Navier–Stokes

#### A1 — Littlewood–Paley/Bernstein infrastructure

Target form:

\[
\|\Delta_j u\|_{L^p}
\le C_B\,2^{3j(1/q-1/p)}\|\Delta_j u\|_{L^q}.
\]

The project freezes `C_B = 4` as a target normalization. This value is not certified here as an optimal universal constant for every chosen cutoff convention.

Status: `TARGET`.

#### A2 — Calderón–Zygmund/Riesz bound

Target:

\[
\|R_iR_j f\|_{L^{3/2}}
\le C_{CZ}\|f\|_{L^{3/2}}.
\]

The value `1.5` is a project target, not presently established in this audit as a theorem for the exact normalization used.

Status: `TARGET`.

#### A3 — Sobolev R3 constant

Target:

\[
\|f\|_6\le C_S\|\nabla f\|_2,
\qquad C_S=0.62\text{ target}.
\]

The decimal value must not be called “sharp” until derived under the exact Fourier/norm conventions used by the formal development.

Status: `TARGET`.

#### A4 — Refined B2.8 alignment / flux control

With the sign convention

\[
\Pi_\Lambda=-\langle P_{>\Lambda}((u\cdot\nabla)u),u_{>\Lambda}\rangle,
\]

the decay-compatible target is

\[
\Pi_\Lambda
\le
\frac{\nu\Lambda^2}{4}R_\Lambda
+2.48\Lambda^{-1/2}R_\Lambda.
\]

Proposed alignment target:

\[
\operatorname{Alignment}(u,\Lambda)\le0.9.
\]

Status: `OPEN TARGET`.

#### A5 — Exact high-frequency energy balance

Target:

\[
\frac{d}{dt}R_\Lambda+D_\Lambda
=
\Pi_\Lambda+F_\Lambda,
\qquad
D_\Lambda\ge c_\nu\Lambda^2R_\Lambda.
\]

The numerical coefficient in the coercive lower bound depends on whether `R_Λ` is defined as `||u_>||²` or `(1/2)||u_>||²`; the formal file must freeze this convention.

Status: `TARGET / standard analytic derivation once definitions are concrete`.

#### A6 — Gronwall closure

Given A4 and A5, prove

\[
R(T)
\le R(0)e^{-aT}
+\int_0^T e^{-a(T-s)}(E(s)+F(s))\,ds,
\qquad a>0.
\]

Status: `CONDITIONAL TARGET`.

#### A7 — ESS endpoint continuation

Formalize the exact Escauriaza–Seregin–Šverák endpoint criterion in the chosen solution class. The shorthand `M3<∞ → T*=∞` is insufficient unless `M3`, the solution class, maximal time, weak/strong solution relation, and continuation mechanism are all explicit.

Status: `TARGET / external theorem formalization`.

### B. Riemann hypothesis

#### B1 — rigorous zeta-ball enclosure

A finite interval-arithmetic certificate may verify nonvanishing or zero counts on specified contours. The targets `r=0.01`, center residual `10^-30`, boundary lower bound `10^-20` are test parameters, not global RH constants.

Status: `TARGET`.

#### B2 — argument principle / Rouché certificate

From validated boundary data, prove a certified zero count in each disk.

Status: `TARGET`.

#### B3 — global bridge

Finite verification, even for very many zeros, does **not** imply RH. A global theorem is needed to exclude every off-critical-line zero. Any explicit-formula theorem must include all truncation/error terms and the step from those bounds to the global critical-line conclusion.

Status: `OPEN WORLD-LEVEL BRIDGE`.

## Formal release criterion

A target moves to `CLOSED` only if:

1. no `sorry`;
2. no unproved `axiom` used for the target;
3. no `True` placeholder;
4. no definition that encodes the conclusion by construction;
5. exact hypotheses and domains are visible;
6. exact dependency DAG is generated;
7. exact Git SHA and CI artifact are archived;
8. independent human/machine second-pass review checks circularity and theorem strength.
