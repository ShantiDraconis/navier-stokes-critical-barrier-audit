# 08 — Forcing

Forced critical balance form:
\[
\frac13\frac{d}{dt}\|u\|_3^3 + c_0\nu D_3
\le C_0\|u\|_3D_3 + F_3,
\]
\[
|F_3|\le \|f\|_3\|u\|_3^2.
\]
Hence schematically:
\[
\frac13\frac{d}{dt}\|u\|_3^3 + (c_0\nu-C_0\|u\|_3)D_3
\le \|f\|_3\|u\|_3^2.
\]

Status: FORMAL / REQUIRES PRECISE HYPOTHESES.
