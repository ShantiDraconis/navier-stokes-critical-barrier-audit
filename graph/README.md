# Graph Model

This directory contains a machine-auditable graph split into:

- `nodes.yaml` for entities (person, repos, commits, files, claims, concepts)
- `edges.yaml` for typed relations
- `schema.yaml` for allowed node and edge types
- Mermaid views:
  - `provenance.mmd`
  - `mathematical-dependency.mmd`
  - `timeline.mmd`
  - `graph.mmd`
