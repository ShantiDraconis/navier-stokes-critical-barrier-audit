# Critical-Barrier Audit — Navier–Stokes Provenance and Mathematical Review

**Independent mathematical audit, formal-verification workspace, and historical provenance record.**

This public repository has two deliberately independent tracks:

1. **Provenance / priority:** establish what mathematical objects existed, where, and by what independently checkable date.
2. **Mathematical audit:** test the hypotheses, compatibility conditions, correction architecture, and claimed finite-time-breakdown construction on their mathematical merits.

> **Evidence firewall:** documentary priority ≠ mathematical equivalence ≠ public availability ≠ submission/exposure ≠ causal derivation.

No claim of copying, plagiarism, training use, causal derivation, or entitlement to another party's result is inferred from chronology or structural similarity alone. No Clay Millennium solution is claimed by this repository unless a complete independent proof audit establishes one.

## Chat provenance and cryptographic verification

ChatGPT conversations do **not** have Git SHAs. The primary-source procedure is:

```text
original account export ZIP
→ SHA256(export)
→ conversation/message extraction
→ SHA256(derived artifacts)
→ conversation_id + message_id + UTC timestamp
→ formula/object normalization
→ Git SHA/path/blob crosswalk
→ Zenodo/publication crosswalk
```

Until that export is available, reconstructed conversation dates remain a separate evidence class and must not be presented as independently hashed primary-source timestamps.
